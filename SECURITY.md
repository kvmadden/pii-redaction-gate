# Security and privacy reports

This is a demonstration project, not a supported product. Do not send real patient data or real identifiers in an issue, a pull request or an email.

If you find text that passes the gate with an identifier left and a `clean` status, that is the most useful report. Please open an issue with a fictional reproduction: the same shape, with invented names and numbers, plus the profile or source you used and the output you got.

For anything you would rather not post in public, email kevin@kvmadden.com.

What the gate does not claim is listed in the README under "Limits" and in every result as `scan.knownGaps`. A report about one of those is still welcome, because it shows which gap matters in practice.
